# TimeTracker

**TimeTracker** is a lightweight Windows app that keeps an eye on which apps you're actually using and for how long. No cloud, no fuss, just a local tracker that helps you understand your digital habits.

---

## What it does

- **Shows you what's running** – right now, in real time. See the active window, process name, and whether you're active, idle, or on pause.
- **Counts your daily total** – a running timer for today's screen time.
- **Knows when you step away** – after 20 seconds of no mouse or keyboard activity, it politely pauses tracking (you can tweak that threshold).
- **Lets you set limits** – pick any process (like `chrome.exe`) and set a time limit in minutes. When you hit it, a popup reminds you to take a break.
- **Gives you a daily dashboard** – pick a date and see a pie chart of your top 5 apps, plus an hourly activity graph.
- **Exports reports** – save a JSON dump of any day's data for deeper analysis.
- **Ignores the noise** – exclude system processes you don't care about (like `explorer.exe`).
- **Starts with Windows** – optional, if you want it always running.
- **Dark or light** – your eyes, your choice.
- **Speaks two languages** – switch between Russian and English (restart required after change).

---

### What you need

- Python 3.7 or newer
- Windows (the app uses Windows APIs to grab window info)

### Build 
You can take exe file in folder build_v1 or build_v2
